# SinglePageBrowser

APK-приложение — браузер для одной страницы.

## Как работает

- **Первый запуск** — диалог с полем ввода URL. Адрес сохраняется и дальше
  открывается автоматически при каждом запуске (хранится в SharedPreferences,
  переживает перезапуски и обновления).
- **Страница** открывается во встроенном WebView на весь экран
  (системные панели скрыты, появляются только свайпом).
- **Смена URL** — тройное быстрое нажатие (интервал < 500 мс) в правый
  верхний угол экрана (~100 dp × 100 dp). Откроется тот же диалог,
  текущий адрес подставлен в поле.
- **Кнопка «Назад»** ходит по истории страницы, а не закрывает приложение.
- **Ошибка загрузки** (нет сети) — белый экран с текстом, нажатие повторяет
  попытку.
- URL нормализуется: если схема не указана, подставляется `https://`.

## Сборка

### Вариант 1 — Android Studio (проще всего)

1. Установите [Android Studio](https://developer.android.com/studio).
2. **Open** → выберите папку проекта `single-page-browser`.
3. Дождитесь синхронизации Gradle (качает SDK автоматически).
4. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
5. APK будет в `app/build/outputs/apk/debug/app-debug.apk` —
   его можно сразу установить на устройство (разрешить «установка
   из неизвестных источников»).

Для релизной подписанной версии: **Build → Generate Signed App Bundle / APK**
(создаётся keystore — сохраните его, без него нельзя обновлять приложение).

### Вариант 2 — командная строка

Нужны JDK 17 и Android SDK (command line tools). Далее:

```bash
# в папке проекта (первая сборка скачает Gradle)
gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

Установка на подключённое устройство:

```bash
gradlew.bat installDebug
```

## Где менять поведение

Всё в одном файле: `app/src/main/java/com/example/singlepagebrowser/MainActivity.kt`

- размер «горячего» угла: `CORNER_DP` (сейчас 100 dp)
- таймаут тройного тапа: `TAP_TIMEOUT_MS` (сейчас 500 мс)
- имя приложения: `app/src/main/res/values/strings.xml` → `app_name`
- цвет иконки: `res/drawable/ic_launcher_background.xml`
